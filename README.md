# 💬 Friendly Chat (FC) — Защищенный E2EE Мессенджер

Полнофункциональный приватный веб-мессенджер с поддержкой сквозного шифрования (E2EE), системных Push-уведомлений, биометрии (Face ID / Touch ID), PWA-режима на мобильных устройствах, таймера исчезновения сообщений и отказоустойчивой маршрутизацией через Cloudflare.

---

## 🚀 Основные возможности

### 1. 🔒 Сквозное шифрование (E2EE)
* **Алгоритмы**: RSA-OAEP 2048-bit (для обмена ключами) + AES-GCM 256-bit (для сообщений и фото).
* Все сообщения и фотографии шифруются на устройстве отправителя до отправки в сеть.
* Сервер не имеет доступа к текстам или фотографиям — для него это бессмысленный зашифрованный набор данных.
* Приватные ключи пользователя защищены мастер-паролем с использованием PBKDF2 (100 000 итераций).

### 2. 🛡️ Комплекс безопасности
* **Face ID / Touch ID / PIN-код**: аппаратная биометрия (WebAuthn Passkeys) и 4-значный PIN для блокировки приложения при сворачивании или неактивности.
* **Privacy Blur (Размытие экрана)**: автоматическое скрытие интерфейса при переключении между приложениями (в меню многозадачности iOS / Android).
* **Anti-Bruteforce**: серверная защита от подбора паролей (блокировка на 10 минут после 5 неверных попыток).
* **Самоуничтожение сообщений (TTL)**: таймер жизни переписки (1 час / 24 часа / 7 дней) с безопасным затиранием нулями (`'0000000000000000'`) на сервере и клиентах.
* **Panic Button («Красная кнопка»)**: мгновенное безвозвратное стирание всех криптографических ключей, кэша и сессий с устройства в 1 клик.
* **Фильтр нежелательных никнеймов**: встроенный серверный фильтр ненормативной лексики при регистрации.

### 3. 🔔 PWA и Системные Push-уведомления (24/7 Free)
* Полноценная поддержка **PWA (Progressive Web App)** с возможностью установки на рабочий стол iPhone и Android.
* Интеграция с **WebPush / VAPID** для мгновенных фоновых уведомлений при закрытом приложении или заблокированном экране.
* Встроенный 8-минутный self-ping механизм Keep-Alive для поддержания сервера активным 24/7 на бесплатном тарифе Render.

### 4. 🌐 Отказоустойчивость и зеркала (Cloudflare)
* **Основной хостинг**: Render (`https://friedlychat.onrender.com`).
* **Резервный прокси**: Cloudflare Worker (`https://friendly-proxy.khomyakov-danila.workers.dev`).
* Автоматическое переключение на резервные шлюзы при сбоях или блокировках сети.

### 5. 📱 Мобильная адаптация
* Полная поддержка **iOS Safe Area Insets** (челка iPhone, Dynamic Island, нижняя полоса жестов).
* Автоматическая подтяжка сообщений к полю ввода при открытии виртуальной клавиатуры (`visualViewport` + `interactive-widget=resizes-content`).
* Авто-капитализация первой буквы предложений на всех устройствах.
* Алфавитная сортировка контактов и поиска пользователей.
* Поддержка фотосообщений и WebRTC аудио/видеозвонков.

## 📁 Структура проекта

```text
friendly-chat/
├── public/
│   ├── index.html          # Главный фронтенд (UI, WebCrypto, WebAuthn, WebRTC, Socket.IO)
│   ├── icon.png            # Фирменная матовая черная иконка «FC»
│   ├── manifest.json       # PWA-манифест для установки на мобильные
│   └── sw.js               # Service Worker для Push-уведомлений и оффлайн-кэша
├── server.js               # Бэкенд Node.js (Express, Socket.IO, Turso DB, WebPush, Anti-Bruteforce)
├── cloudflare-worker.js    # Резервный прокси-воркер Cloudflare
├── package.json            # Зависимости и скрипты
├── package-lock.json       # Фиксация версий пакетов
├── .env                    # Переменные окружения (Turso DB URL, VAPID Keys)
├── .gitignore              # Игнорируемые Git файлы
└── README.md               # Документация проекта
```

## 🛠️ Запуск локально

1. Установите зависимости:
```bash
npm install
```

2. Запустите сервер разработки:
```bash
npm start
```
Сервер будет доступен по адресу: `http://localhost:3000` (или на указанном в `.env` порту).
